# 🚚 Vehicle Routing Optimization using Genetic Algorithm

This project solves the Vehicle Routing Problem (VRP) using a Genetic Algorithm to minimize total travel distance while ensuring vehicle capacity constraints are met. It automatically assigns customers to vehicles, splits oversized demands, evaluates route fitness, and evolves solutions to find an optimized delivery plan.

## ✨ Key Highlights
- Genetic Algorithm for route optimization
- Valid capacity & demand-aware routing
- Customer demand splitting
- Crossover, mutation & elitism
- Distance-based fitness evaluation
- Fitness vs Generation graph visualization
